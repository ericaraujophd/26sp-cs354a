:::{admonition} 📅 Final Project

This week is dedicated to review and final assessment. There are no new topics — use this time to consolidate everything covered in weeks 1–7.

For the final project, you should be able to demonstrate mastery of all SLOs from the course, including:

- Writing and filtering `SELECT` queries (Weeks 01–03)
- Ordering, paginating, and computing values (Week 04)
- Joining multiple tables (Week 05)
- Aggregating and grouping data (Week 06)
- Designing tables, writing DML statements, and using set operations (Week 07)
